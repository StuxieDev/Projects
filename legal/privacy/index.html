Privacy Policy

This site is static and built to be private by default. It never sends your data anywhere.

Effective: September 2026 — Last updated: September 2026

The short version

StuxieDev Projects is a static site — plain HTML, CSS, and JavaScript with no server-side application behind it. There is no account system, no database, and no form on this site that sends data anywhere.

Personal data None is collected by this site. We don't ask for your name, email, or any identifying information.
Cookies & tracking None. No analytics scripts, no tracking pixels, no third-party ad networks.
Hosting This site is hosted on GitHub Pages. GitHub, as the hosting provider, may log standard web server data (IP address, request path, timestamp) per its own privacy policy — that logging happens at the infrastructure level, not something this site controls or receives.
Advertising None. This site carries no ads and sells no data.

Linked projects

Each project listed on this site links out to its own website and GitHub repository, which may have their own privacy practices. This policy covers only the StuxieDev Projects index site itself.

Children's privacy

This site does not knowingly collect information from anyone, children included — it doesn't collect information from anyone at all. Note that one linked project (TIGHC) is age-gated 18+ on its own site.

Changes to this policy

If this policy changes in any meaningful way, the date above will be updated.
